digenx

Apna Digen agent CLI — terminal se Digen AI agents se chat karo. Brief do, video banao.

✅ 100% free hai — koi credit system nahi.

Features

  • Chat — interactive, streaming jawab
  • Video length — jitni lambi chahiye, koi limit nahi (--duration)
  • Frame size — koi bhi size: 16:9, 9:16, 1:1, 1920x1080 (--aspect)
  • Sessions — history, resume, delete
  • Image attach — chat me tasveer bhejo
  • MCP server — Claude Code / Cursor se direct
  • Google login — browser se simple login

Install

git clone https://github.com/MisbahAliKhokha/digenx.git
cd digenx
./install.sh

Use

digenx login
digenx chat
digenx chat --duration 3600 --aspect 9:16
